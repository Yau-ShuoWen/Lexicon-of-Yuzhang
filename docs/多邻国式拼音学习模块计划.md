# 多邻国式拼音学习模块计划

> 仿照多邻国的拼音 / 语音学习体验，基于本项目已有的方言拼音方案、简繁体结构、国际音标体系，构建一个独立的交互式拼音学习模块。

---

## 一、背景与定位

### 1.1 项目已有积累

| 领域 | 现有资产 | 说明 |
|------|---------|------|
| **方言拼音方案** | LAC（南昌话）、CED（成都话）、WUH（武汉话）、GHZ（杭州话） | 每个方言有独立的拼音编码体系、音段表、音节表、音调表 |
| **普通话数据** | `mdr_char` 表（4808汉字 + 拼音 + 注音）、3500/4800常用字标记 | 作为对比基准和多方言映射中心 |
| **简繁体对** | `ScTcText` 类、`UString/UChar` 文本体系、机翻管线（HanLP + 自定义字集） | 支持 sc/tc 双语内容 |
| **国际音标** | `IPASyllEntity` / `IPAToneEntity` / `IPACache` — 音节、音段、音调三表 | 每个方言有 IPA 映射，可生成严式/宽式音标 |
| **课程/内容框架** | `CourseEntity`（chapter/section 结构）、`CourseCatalog`、`RichTextUtil` 富文本渲染 | 已有简单的课程内容管线 |
| **富文本标记语言** | `[]`拼音标注、`{b }`粗体、`{c }`链接、`{n }`注解等 | 支持拼音→读音自动转换 |

### 1.2 设计目标

**核心目标**：构建一个独立 `pinyin-learning` 模块（或子项目），提供类似于多邻国的拼音学习体验，包括：

1. **声母 / 韵母 / 音调 分级学习**：从音节拆分到拼读
2. **简繁对照学习**：同时展示简体字形和繁体字形
3. **多方言映射**：对比普通话拼音 ↔ 方言拼音 ↔ 国际音标
4. **交互练习**：听音选字、看字选音、拼写输入、配对练习
5. **学习进度跟踪**：用户学习记录、复习提醒、完成度统计

## 三、学习内容体系

### 3.1 课程路线图（模仿多邻国）

#### 第一阶段：初识拼音（入门）
| 课次 | 内容 | 练习重点 |
|------|------|---------|
| 1-1 | 什么是拼音 | 展示声母+韵母+音调的概念 |
| 1-2 | 6个单韵母 `a o e i u ü` | 听音选韵母 |
| 1-3 | 声母入门1 `b p m f d t n l` | 看字选声母 |
| 1-4 | 声母入门2 `g k h j q x` | 声韵拼读练习 |
| 1-5 | 声母入门3 `zh ch sh r z c s y w` | 完整声母表 |
| 1-6 | 4个音调 | 听音辨调 |

#### 第二阶段：拼读进阶
| 课次 | 内容 | 练习重点 |
|------|------|---------|
| 2-1 | 复韵母 `ai ei ui ao ou iu ie üe er` | 韵母识读 |
| 2-2 | 前鼻韵母 `an en in un ün` | 对比 i/n 韵尾 |
| 2-3 | 后鼻韵母 `ang eng ing ong` | 对比 n/ng 韵尾 |
| 2-4 | 整体认读音节 `zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying` | 整体认读练习 |
| 2-5 | 拼读综合 | 看汉字选完整拼音 |

#### 第三阶段：汉字与简繁
| 课次 | 内容 | 练习重点 |
|------|------|---------|
| 3-1 | 常见汉字300（一） | 看汉字选拼音+听音选汉字 |
| 3-2 | 常见汉字300（二） | 配对练习 |
| 3-3 | 简繁对照入门 | 简体↔繁体配对 |
| 3-4 | 常用简繁差异字50例 | 选择对应的简繁形式 |

#### 第四阶段：方言对比（特色内容）
| 课次 | 内容 | 练习重点 |
|------|------|---------|
| 4-1 | 普通话 vs 南昌话 | 同一汉字两种读音对比 |
| 4-2 | 普通话 vs 成都话 | 国际音标对照 |
| 4-3 | 南昌话声母特点 | 方言特有声母（如 ng-） |
| 4-4 | 成都话韵尾对比 | 入声韵尾对照 |
| 4-5 | 方言综合挑战 | 听一段方言录音，选择对应汉字 |

#### 第五阶段：国际音标
| 课次 | 内容 | 练习重点 |
|------|------|---------|
| 5-1 | IPA入门 | 基础音标符号认识 |
| 5-2 | 声母IPA对照 | b→[p] p→[pʰ] 等 |
| 5-3 | 韵母IPA对照 | a→[a] i→[i] 等 |
| 5-4 | 五度标记法 | 音调与数字/线图对照 |

### 3.2 练习题型设计

| 题型 | 说明 | 实现方式 |
|------|------|---------|
| **听音选择** | 播放音频，选择对应的拼音/汉字 | 利用已有 `AudioResource` / 音频上传机制 |
| **看字选音** | 显示汉字，选择正确拼音 | 从 `mdr_char` / `xxx_char_pinyin` 生成干扰项 |
| **拼写输入** | 显示汉字+音调描述，用户输入拼音 | 校验输入为 `SPinyin` 格式 |
| **配对连线** | 声母↔韵母、简↔繁、拼音↔汉字配对 | 前端交互 + 后端校验 |
| **音调识别** | 听同一个音节的不同音调（mā má mǎ mà） | 利用 `Shengdiao` 数据 |
| **简繁对照** | 显示简体选繁体 / 显示繁体选简体 | 利用 `ScTcText` 数据 |
| **方言对比** | 同一汉字的普通话拼音 vs 方言拼音 | 利用 `xxx_char_mdr` 对应表 |
| **国际音标阅读** | 看 IPA 选择对应的汉语拼音 | 利用 `xxx_ipa_syllable` / `IPACache` |

### 3.3 内容数据来源

所有练习题的数据都从**已有数据**中动态/静态生成：

```
mdr_char (普通话汉字拼音)
  ├─→ 汉字 → 拼音映射（看字选音/听音选字）
  ├─→ 拼音 → 汉字映射（拼写输入答案校验）
  └─→ 3500/4800常用字（难度分级）

xxx_char + xxx_char_pinyin (方言字表)
  ├─→ 方言读音变体（多音字处理）
  └─→ 方言特有汉字（特殊标记1/2/3）

xxx_ipa_syllable (方言音节表)
  └─→ 拼音 ↔ 国际音标对照（IPA阅读练习）

ScTcText (简繁对)
  └─→ 简繁配对练习

RichTextUtil 富文本管线
  └─→ 题目文本渲染（拼音标注自动转换）
```

### 4.2 学习引擎关键模块

#### 练习生成器 (`ExerciseGenerator`)

```
输入: 课次配置 (lesson_id)
  │
  ├─ 1. 解析 content_json
  │      { "focus": ["b", "p", "m"], "type": "initials",
  │        "dialect": "MDR", "count": 10 }
  │
  ├─ 2. 从数据库查询音段/汉字
  │      SELECT FROM mdr_char WHERE pinyin LIKE 'b%'
  │
  ├─ 3. 生成干扰项 (distractors)
  │      - 相近声母：p/d/f
  │      - 同一音调但不同声母
  │      - 同一声母不同音调
  │
  └─ 4. 组装为 ExerciseDTO
         返回给前端
```

#### 间隔重复引擎 (SM-2 算法)

```
复习排队：
  1. 新练习 → 首次复习间隔 = 1天
  2. 答对 → 间隔 *= 轻松度(默认2.5)
  3. 答错 → 重置间隔 = 1天，轻松度 -= 0.2
  4. 下次复习时间 = now + 间隔天数
```

## 七、关键难点与风险

1. **音频资源缺失**：目前普通话音频没有现成数据集，需要外部采集（如 TTS 生成或开源语音库）
2. **方言音频更难获取**：方言发音人稀少，可能需要专业的录音/标注
3. **干扰项生成质量**：自动生成的干扰项要保证合理（不能太离谱也不能太接近），需要结合语言学规律
4. **简繁对照的精度**：部分汉字简繁并非一一对应（如「干/乾/幹」），需要特殊处理
5. **前端工作量**：多邻国风格的交互 UI（进度树、动画、音效）开发量较大

## 八、可选的扩展方向

- **AI 发音评测**：用户录音后利用语音识别评测发音准确度
- **方言语音合成**：为各地方言生成 TTS 音频
- **学习社区**：排行榜、好友比拼
- **方言地图**：展示各地方言语音特点的地理分布
- **自适应学习**：根据用户答题情况动态调整难度
