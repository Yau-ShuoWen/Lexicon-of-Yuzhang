# 日记图片新旧格式

## 标记

- 旧版本：`{p 125}` 或 `{p 说明=>125}`。代码保留读取兼容，作为旧内容标记。
- 新版本：`{p uuid}` 或 `{p 说明=>uuid}`。UUID 来自图片对象名，不使用连续的数据库 ID。
- 显示宽度可附加 `~160`，单位为像素，例如 `{p uuid~240}`。
- 图片可嵌入普通文字、列表行和表格单元格；一组相邻图片可写成 `{pg {p uuid1}{p uuid2}}`。

正文仍不保存 OSS 签名 URL。原图保留在 OSS；新上传的 JPEG/PNG 图片仅在最长边超过 2000 像素时另存最长边 1600 像素的缩略图。JPEG 缩略图用 0.92 质量编码，PNG 保持无损。正文优先加载缩略图，点击预览及下载使用原图。旧图片、小图和 WebP 暂用原图作正文图源。

## 旧内容

旧正文保留数字图片标记，不统一迁移。旧标记继续可读取；需要更新的少量内容由项目负责人重新上传。日记历史表保持原样。

编辑框会给数字标记显示“旧图”。单图可用旁边的复制按钮或选中后按 Ctrl+C，系统剪贴板写入 PNG 图片数据，同时保留日记来源信息；贴回日记时经授权接口读取 OSS 原图，重新上传并生成新标识。编辑框中的图片按原始比例显示；鼠标位于正文编辑框任意位置时按 F2，可进入整篇日记的持续预览。在预览中可用图片旁的加减按钮调整并保存单图的显示宽度。

## 回收站

先手动执行 `docs/数据库/图片表格/日记图片回收站.sql`，再部署依赖该列的后端代码。新上传而未写入正文的图片带回收时间；保存日记后，仍被任一版本正文引用的图片清除此标记，未引用的图片保留标记。回收站只列出图片，不执行物理删除。旧图片不会被批量移动；重新保存对应日记时会更新它们的引用标记。
