# 拼音类内容：使用`[]`

## 说明

1. 使用半角方括号
2. 文本内部允许有空格，会单独解析，如`[lan4 cong1]`等于`[lan4] [cong1]`，`[+lan4 cong1]`等于`[+lan4] [+cong1]`，拼音内部不能空格

## 写法

### 方言拼音

- 标识：直接使用中括号包裹即可
- 拼音：使用方言拼音的输入版本。

> - 编辑者写的：`[gon1]`
> - 用户看到的：使用字体展示的`gòn`

### 国际音标（音系内部）

- 标识：在左括号后加一个`*`
- 拼音：使用方言拼音的输入版本。

> - 编辑者写的：`[*gon1]`
> - 偏好为「方言拼音」用户看到的：`gòn`
> - 偏好为「国际音标」用户看到的：`kɔŋ˦˨`

### 国际音标（音系外部）

- 标识：在左括号后加一个`-`
- 拼音：左侧写汉语学界的国际音标，右侧写音调的五度标记法，中间用`-`

> - 编辑者写的：`[-ɕyia_42]`
> - 用户看到的：使用字体展示的`ɕyia˦˨`

### 汉语拼音

- 标识：在左括号后加一个`+`
- 拼音：使用汉语拼音输入版本。

> - 编辑者写的：`[+yi1]`
> - 用户看到的：`yī`

### 自定义拼音

- 标识：在左括号后加一个`#`
- 拼音：左侧写上述音系外部的国际音标，右侧写造出来的方言拼音，中间用`=`

> - 编辑者写的：`[#sio_45=siō]`
> - 偏好为「方言拼音」用户看到的：`siō`
> - 偏好为「国际音标」用户看到的：`sio˧˥`

### 其他拼音

- 标识：在左括号后加一个`/`
- 拼音：里面可以有任何拉丁系符号，仅为了改变字体强调这是其他形式的拼音，所以不会检查是否合理

> - 编辑者写的：`[/aoeiuü]`
> - 用户看到的：`aoeiuü`

# 拼音块

**仅用于程序自动生成，是拼音块的扩展内容，里面包括特殊字符，在编程的时候默认不会作为用户输入，也不应该在任何地方展示出来**

`▕折叠口│标题1┆内容1│标题2┆内容2│可增减……▏`

折叠口的格式类似于markdown里的`代码块`

例如：
数据库里存的：`这个词语读作 [cẹ́n]`
后端生成的： `这个词语读作▕[cẹ́n]│印刷和书写┆[cẹ́n]│键盘输入┆[ceen2]│国际音标┆[tsɨn_˨˦]▏`
用户看到的：这个词语读作`cẹ́n`（中括号流程是拼音类）
点进去之后

```
对齐
------------------
|印刷和书写 |cẹ́n   |
|键盘输入   |ceen2 |
|国际音标   |tsɨn˨˦ |
-----------------
```

# 注释：使用`/**/`

1. 只会在编辑文本框中看见，不作为最终显示
2. 可以用于结构校对随笔

> - 编辑者写的：`所以结论为此。/*此处存疑，需要更多信息*/`
> - 用户看到的：`所以结论为此。`

# 富文本：使用`{_ }`

| 格式名称 | x是什么字母        | 内层嵌套 | 外层嵌套 | 说明             | 代码完成 |
|------|---------------|------|------|----------------|------|
| 标题   | h(header)     | ×    | ×    | 标题是单独的         | ✓    |
| 粗体   | b(bold)       | ×    | ✓    | 字体格式，只能能作为最里一层 | ✓    |
| 斜体   | i(italic)     | ×    | ✓    | 字体格式，只能作为最里一层  | ✓    |
| 删除划线 | d(delete)     | ×    | ✓    | 字体格式，只能作为最里一层  | ✓    |
| 代码条  | code          | ×    | ✓    | 字体格式，只能作为最里一层  | ✓    |
| 词语链接 | c(ciyu)       | ✓    | ✓    | 链接的字体部分可以有格式   | ✓    |
| 汉字链接 | z(zi，h被占用了)   | ✓    | ✓    | 链接的字体部分可以有格式   | ✓    |
| 链接   | l(link)       | ✓    | ✓    | 链接的字体部分可以有格式   | ✓    |
| 注解   | n(note)       | ✓    | ×    | 注解必须在最外层       | ✓    |
| 保护文本 | prot(protect) | -    | -    | 因为特殊格式不可以复制的文本 |      |
| 音频   | a(audio)      | ×    | ×    | 设计中            |      |
| 图片   | p(picture)    | ×    | ×    | 独占一行，保存图片 ID   | 设计完成 |
| 视频   | v(video)      | ×    | ×    | 设计中            |      |

## 内容

### 标题

说明略

### {b 粗体}

> - 编辑者写的：`这里用法{b 不同于}普通话`
> - 用户看到的：这里用法**不同于**普通话

### {i 斜体}

> - 编辑者写的：`我也不知道什么时候会用上{i 斜体}的写法`
> - 用户看到的：我也不知道什么时候会用上*斜体*的写法

### {d 删除划线}

> - 编辑者写的：`这是一个姚说文{d 神经}的想法`
> - 用户看到的：这是一个姚说文~~神经~~的想法

### {code 代码条}

> - 编辑者写的：`请点击{code Ctrl+F}来全文查找`
> - 用户看到的：请点击<code>Ctrl+F</code>来全文查找

### {c 词语链接=>词语}

- 可以导向对应词汇

> - 编辑者写的：`{c 南昌}`
> - 用户看到的：[南昌](https://yuzhangci.com/sc/lac/c/南昌) ---> 创建sc/lac/c/南昌 的链接

- 可以重定向

> - 编辑者写的：`{c 豫章=>南昌}`
> - 用户看到的：[豫章](https://yuzhangci.com/sc/lac/c/南昌) ---> 还是创建sc/lac/c/南昌 的链接

### {链接

> - 编辑者写的：`{l 这是一个链接=>https://yuzhangci.com/sc/lac/ysw}`
> - 用户看到的：[这是一个链接](https://yuzhangci.com/sc/lac/ysw)

### 注解

> 主要用在辞书里，因为说明的可以直接跟在后面。
> - 编辑者写的：`他话{n 说}什哩`
> - 用户看到的：他话^什哩 鼠标在^上 原书注：说

### 图片

图片保存数据库中的稳定图片 ID，不直接保存 OSS URL。图片标记必须独占一行。

> - 编辑者写的：{p 125}
> - 编辑者写的（带说明）：{p 秋日下午的窗户=>125}
> - 用户看到的：对应图片；带说明时在图片下方显示说明

具体上传、权限、引用同步和渲染方案见《日记富文本图片拖放设计》。

# 跨行：行首标注

### 无序列表

- 标识：行开头`-`，需要空格

```
- 第一条
- 第二条
- 第三条
```

效果：

- 第一条
- 第二条
- 第三条

### 有序列表

- 标识：行开头`+`，需要空格

```
+ 第一条
+ 第二条
+ 第三条
```

效果：

1. 第一条
2. 第二条
3. 第三条

# 表格

基础内容，适配同Markdown

无头表格，直接不写表头也可以工作，常常用于第一列是表头的情况

```
|---|---|---|
|内容|内容|内容|
|内容|内容|内容|
```

特殊格式

```
|列1|列2|列3|
|---|---*|---+|
|短语|固定长列|自动|
```

- 没有标记时限制为内容所需的宽度，不额外填满剩余空间
- `!`是上述写法的旧别名；读取时仍然支持，重新保存时统一写成无标记的`---`
- `*`表示这个列会固定占用一个较长的宽度（约等于手机端的屏幕不用翻动看完的宽度）
- `+`表示使用Markdown式的自动宽度，分配表格中的剩余空间

## 合并单元格

只有单元格内容完全等于合并标记时才会生效：

- `#>`与左侧单元格横向合并
- `#^`与上方单元格竖向合并
- 合并后的内容默认水平、垂直居中

```
|分类|名称|说明|
|---|---|---+|
|水果|苹果|红色|
|#^|香蕉|黄色|
|合并说明|#>|自动占据两列|
```

矩形区域也可以同时横向、竖向合并。第一行使用`#>`扩展宽度，后续行需要在整个合并宽度内都写`#^`：

```
|合并区域|#>|其他|
|#^|#^|其他|
```

无法找到左侧或上方单元格的标记按普通文本显示；合并不会跨越表头和正文。
